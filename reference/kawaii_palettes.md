# Kawaii palettes

The 30 palettes of the Kawaii collection, each a character vector of hex
colours in printed swatch order.

``` r

kawaii_tri_01
```

## Format

A character vector of hex colour strings.

`kawaii_bi_01`: bicolor, 2 colours (#5C4D8C, \#D0D959).

`kawaii_tri_01`: tricolor, 3 colours (#F4C8DD, \#0097DC, \#3BB699).

`kawaii_tri_02`: tricolor, 3 colours (#4AB0DF, \#D84D96, \#8255A0).

## Details

2 of them contain a provisional reading and are marked `"review"` in the
catalogue; see
[`palettes_needing_review()`](https://paulgp.com/japanesecolors/reference/palettes_needing_review.md).
